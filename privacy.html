Privacy & Data Practices

Privacy & Data Notice

Effective September 2026 — written for exactly what this site does, not boilerplate.

Overview What's collected Who processes it Cookies & storage Your choices

01Overview & scope

This notice covers what happens to your information when you browse this portfolio, use the contact form, or talk to the AI assistant embedded on the site. It applies only to omerfarooq223.github.io — not to the GitHub repositories, live project demos, or social profiles it links out to.

I built and run this site myself; there's no company or marketing team behind it. I don't run behavioral advertising, sell or rent personal data, or load analytics or tracking scripts of any kind.

02What information is collected

Source What's collected Why Retention
Contact form / email Name, email address, message content Replying to your inquiry Kept in my inbox until resolved; deleted on request
AI assistant Your message text and IP address Generating a relevant answer; blocking abuse Message text isn't stored; IP held in memory up to 10 minutes, then discarded
Hosting logs IP address, user-agent, timestamp, status code Keeping the site online and secure Set by GitHub Pages' and Vercel's own infrastructure — see below

Contact form & email

When you write to momerfarooq223@gmail.com or use the contact form, I use what you send strictly to respond — whether that's about an internship, a freelance project, or a general question. It's never added to a mailing list.

AI assistant

The chatbot on this site calls a backend endpoint (/api/chat) that forwards your message to Groq's inference API and streams the reply back. A temporary, in-memory rate limiter records the requesting IP address to prevent denial-of-service abuse.

Chat messages are not written to a database — they exist only long enough to generate a reply. The IP record used for rate-limiting expires automatically after 10 minutes.

Hosting logs

Like almost every website, the infrastructure serving this page — GitHub Pages for the static site, Vercel for the chat endpoint — automatically records request-level data such as IP address, user-agent, and status code. I don't have a dashboard of your individual visits; this is standard infrastructure logging, governed by each provider's own policy, covered next.

03Who processes it

This site doesn't run on a server I manage — it's deployed the way most modern static sites are, through a small number of infrastructure providers. Each sees request-level data as a normal part of serving the page or answering a chat message.

Provider Role Their policy
GitHub Pages Serves the static site and assets over its CDN GitHub Privacy Statement
Vercel Hosts the serverless function behind /api/chat Vercel Privacy Policy
Groq Runs the language model that generates the assistant's replies Groq Privacy Policy

None of these providers are instructed to use your data beyond running the service. I don't layer any analytics, session-replay, or fingerprinting scripts on top of what they already log by default.

04Cookies & local storage

This site sets zero third-party tracking, analytics, or advertising cookies. The only client-side storage is functional:

Key Storage Purpose
portfolio-theme localStorage Remembers your dark/light mode choice across visits
portfolio-entry sessionStorage Skips the entrance animation for the rest of the browser session

Both values are read only by this site's own code, are never transmitted to a server, and can be cleared at any time through your browser's site settings.
