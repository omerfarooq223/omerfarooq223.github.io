Privacy & Data Notice

Effective September 2026 · Last updated October 18, 2026

01Overview & scope

This notice covers what happens to your information when you browse this portfolio, email me, or talk to the AI assistant embedded on the site. It applies only to omerfarooq223.github.io — not to the GitHub repositories, live project demos, or social profiles it links out to.

I built and run this site myself; there's no company or marketing team behind it. I don't run behavioral advertising, and I don't sell or rent personal data. This site does use Microsoft Clarity for website analytics and session recordings, as described below.

Email

When you write to momerfarooq223@gmail.com, I use what you send strictly to respond — whether that's about an internship, a freelance project, or a general question. It's never added to a mailing list.

AI assistant

The chatbot on this site calls a backend endpoint (/api/chat) that forwards your message to Groq's inference API and streams the reply back. A temporary, in-memory rate limiter records the requesting IP address to prevent denial-of-service abuse.

This site's application does not maintain a chat-history database. Messages are still sent to Groq for processing, and infrastructure providers may handle request data under their own policies. The site's in-memory IP rate-limit entries expire after 10 minutes.

Hosting logs

Like almost every website, the infrastructure serving this page — GitHub Pages for the static site, Vercel for the chat endpoint — automatically records request-level data such as IP address, user-agent, and status code. These logs are handled according to each hosting provider's privacy and retention policies. Clarity session recordings are described separately below.

Website Analytics and Microsoft Clarity

This portfolio uses Microsoft Clarity to understand how visitors interact with the website and improve the browsing experience.

Microsoft Clarity may collect information about page visits, clicks, scrolling behavior, device and browser characteristics, approximate geographic location, and website interactions through heatmaps and session recordings.

Clarity uses cookies and similar tracking technologies to analyze website usage. Information collected through Clarity is processed by Microsoft in accordance with its privacy practices. For more information, please visit the Microsoft Privacy Statement.

03Who processes it

This site doesn't run on a server I manage — it's deployed the way most modern static sites are, through a small number of infrastructure providers. Each sees request-level data as a normal part of serving the page or answering a chat message.

04Cookies & local storage

Microsoft Clarity uses cookies and similar tracking technologies for analytics and session recordings. The site's other client-side storage is functional:

Browser storage used by the site

These two preference values are used locally by the site's scripts; they are not intentionally sent with requests. You can clear them through your browser's site settings.
